HOW TO USE
═════════════════════════════════════════════════════════════════════════════

QUICK START:
  1. Open index.html in web browser
  2. Click on a module (e.g., "Belt Scale E4/E5")
  3. Fill in the form (date, PIC, inspection data)
  4. Upload photos (drag & drop or click)
  5. Click "💾 Simpan ke Database"
  6. ✓ Data saved with photos!

FOR VIEWING HISTORY:
  1. Open history.html
  2. Filter by module or search by PIC name
  3. Click "Edit" to view/modify a record
  4. Click "Hapus" to delete a record

FOR PRINTING:
  1. Complete the inspection
  2. Click "🖨️ Download PDF"
  3. Open PDF in new tab
  4. Print to paper

SUPABASE DATABASE STRUCTURE
═════════════════════════════════════════════════════════════════════════════

Table: pm_records

Columns:
  id              UUID PRIMARY KEY
  modul           TEXT (e.g., "BELT CONVEYOR E4-E5")
  tanggal         DATE
  pic             TEXT (Person in Charge)
  work_order      TEXT
  unit            TEXT (e.g., "Unit 7")
  data            JSONB (all form data + images)
  created_at      TIMESTAMP
  updated_at      TIMESTAMP

Example record:
  {
    "id": "123e4567-e89b-12d3-a456-426614174000",
    "modul": "BELT CONVEYOR E4-E5",
    "tanggal": "2026-06-01",
    "pic": "Ahmad Ridho",
    "work_order": "WO-001",
    "unit": "Unit 7",
    "data": {
      "checks": {...},
      "config": "e45",
      "images": {
        "1": [{name: "photo1.jpg", dataUrl: "data:...", type: "image/jpeg"}],
        "2": [...]
      }
    },
    "created_at": "2026-06-01T10:30:00Z",
    "updated_at": "2026-06-01T10:30:00Z"
  }

SECURITY & PRIVACY

⚠️  WARNING:
  - Supabase API key is visible in config.js
  - Use public/anon key only (not service key)
  - Consider using Row Level Security (RLS) on Supabase
  - Images stored as base64 in database (be aware of size)

✅ BEST PRACTICES:
  - Use Supabase RLS policies to restrict access
  - Only allow authenticated users to write
  - Regular backups of database
  - Monitor for unauthorized access
