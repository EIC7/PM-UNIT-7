🚀 HOW TO USE

Local Testing:
  1. Download all 5 code files to a folder
  2. Run HTTP server:
     - Python 3: python -m http.server 8000
     - Python 2: python -m SimpleHTTPServer 8000
     - Node.js: npx http-server
  3. Open browser: http://localhost:8000/fegt.html

GitHub Deployment:
  1. Read GITHUB-SETUP.md
  2. Create GitHub repository
  3. Upload files to GitHub
  4. Enable GitHub Pages
  5. Access via: https://USERNAME.github.io/fegt-module/fegt.html

🔧 CONFIGURATION

Before deployment, update in fegt-config.js:

1. Supabase URL:
   var SUPA_URL = 'https://YOUR_PROJECT_ID.supabase.co';

2. Supabase API Key:
   var SUPA_KEY = 'YOUR_API_KEY';

3. Table name (default: pm_records):
   var SUPA_TABLE = 'pm_records';

⚠️  Ensure Supabase table has these columns:
    - id (integer, primary key)
    - modul (text)
    - tanggal (date)
    - pic (text)
    - work_order (text)
    - unit (text)
    - data (jsonb)
    - created_at (timestamp)
    - updated_at (timestamp)
