✏️ Input Manual

Input data langsung melalui tabel di bawah.
Klik ＋ Tambah Baris untuk menambah baris baru.
Klik ＋ Tambah Kolom untuk menambah nomor WO, deskripsi asset, atau informasi lainnya.

🗂 Referensi Template Kolom
Belum ada referensi tersimpan.
➕ Tambah Kolom Baru
🗑 Hapus Baris?

Data baris ini akan dihapus permanen dari database. Lanjutkan?

🗑 Hapus Kolom?

Kolom — akan dihapus dari semua baris. Data di kolom ini akan hilang permanen setelah disimpan.

➕ Tambah Input Utama Baru

Masukkan nama kategori/jenis asset baru (contoh: Flow Meter, Pressure Gauge, dsb.)

🗑 Hapus Input Utama?

Semua data di tab — akan dihapus permanen dari database. Tindakan ini tidak dapat dibatalkan.

🗂 Simpan Referensi Template Kolom

Simpan konfigurasi kolom tab aktif sebagai template. Masukkan nama dan sandi untuk mengamankan referensi ini.

🗑 Hapus Referensi?

Masukkan sandi untuk menghapus referensi —.

🔄 Reset Kolom Tambahan?

Semua kolom tambahan pada tab — akan dihapus. Kolom fix (Asset Tag, Deskripsi, Lokasi, PIC) tetap ada.
